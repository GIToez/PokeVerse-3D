## In one paragraph

A 3D, browser-based Pokémon MMO set in Kanto. There is one continuous outdoor map (about 722 × 537 m, 39 towns and routes)
plus 71 interior and dungeon scenes. 248 species have 3D models, and 123 of them spawn in the wild. Combat with wild Pokémon
is real time, and capture uses the Gen III formula. There are 8 gyms, 56 story missions, trading, chat, staff-run raids, live
events and a large GM admin panel. The main limitation: **the bundled server is a development stand-in, not the production
server the client was built for.** Most notably, turn-based trainer, gym and Elite Four battles don't work for logged-in players.

## What works

- **Exploration:** walk the whole of Kanto without loading screens; doors lead to 71 interiors and dungeons (Mt. Moon,
  Rock Tunnel, Pokémon Tower, Silph Co., Seafoam, Victory Road, Cerulean Cave, S.S. Anne and more). Some Sevii Islands
  scenes (One Island, Mt. Ember, Icefall Cave) are also present.
- **Wild combat and capture:** real-time fights with type effectiveness, STAB, IVs and natures; capture with shake animations.
- **Team management:** party of 6, box, follower Pokémon, evolution (level, stone, trade, friendship, time of day).
- **Progression:** badge-based level caps, 56 story missions, Pokédex with knowledge levels and titles.
- **Multiplayer:** see other players, their outfits, partners and mounts; chat; trading; staff-run raids; live events.
- **Admin:** edit almost every data file from the browser; place scenery and NPCs; paint terrain; manage players live.
- **Languages:** English by default; Portuguese is available; the source text is being moved to English (see below).

## What doesn't work, or is missing

**Server gaps.** These come from the bundled server being a stand-in for a production server that isn't in this project:

| Gap | Effect |
|---|---|
| No turn-based battle engine on the server | Logged-in players can't battle trainers, gyms or the Elite Four. Offline play (no account) uses the client's own engine for trainers and gyms |
| Elite Four | Unplayable locally (account-only, needs the missing battle engine) |
| No world server | Each client spawns its own wild Pokémon, so players don't see the same wilds and captures are trusted from the client |
| Protocol mismatch | Client protocol version 18, server 15. No visible error, but the client expects messages the server never sends (progress pass, door checks, direct messages, Elite Four runs) |

**Gameplay not implemented:** status conditions (burn, sleep, paralysis…), EVs, PvP, fishing, the Safari Zone game mode,
crafting, day/night lighting and weather, key remapping, the premium shop and the mount shop.

**World gaps:** the Underground Path is missing. Indigo Plateau has only its interior (the Pokémon League center and the
Elite Four rooms), with no outdoor area. Pokémon Mansion has a single floor. The Safari Zone dungeon scene (2100011)
exists but no door leads to it. `zonas_spawn.json` is empty (spawns are defined in `habitats.json` instead). All three
Mt. Moon floors are named "1F" in the scene data.

**Code layout quirk:** the main game code is an inline script inside `index.html` (about 9,000 lines). `idx_mod_0.mjs` is an
older copy of it that nothing loads; editing it has no effect.

**Content gaps:** 751 Pokédex species have no model, so they can't appear in the world. The Giratina and Arceus mounts point
to model files that don't exist. Level, Net, Nest and Repeat Balls behave like a normal Poké Ball.

## Things to decide

1. **Repository visibility.** This GitHub repository is public, so the `_novos/` code and all game assets on the pull request
   branch are visible to anyone. Consider making it private.
2. **Rights.** Pokémon names, models and music are Nintendo / Game Freak / The Pokémon Company property, and `_novos/` has the
   copyright notice above. Running this publicly carries legal risk independent of any code work.
3. **Battle server.** For trainer, gym and Elite Four battles to work with accounts, the server needs a turn-based battle
   handler for the `bat_*` messages. Alternatively, the client could be changed to use its local engine even when logged in.
   The client's local engine already exists in `idx_mod_0.mjs`.
4. **Security before going public:** see `docs/SECURITY.md` (retire legacy password hashes, restrict CORS, add a connection cap).

## Language migration status

English is now the **source** language. Where text has been rewritten in English, Portuguese is produced from
`public/data/locale/*_pt.json` (generated by `node tools/locale_invert.mjs`). Text not yet rewritten is still translated
from Portuguese by `*_en.json`, so the game is fully English either way.

| Area | Source text |
|---|---|
| HUD layout (`ui/hud_layout.json`) | English |
| Menus (`menus.mjs`) display text | English |
| Place names (`nomes_en.json`) | Dictionary covers every scene and area name |
| Main game (inline script in `index.html`), other modules, data files (`missoes.json`, `npcs_glb.json`, `menus_dados.json`…) | Still Portuguese source, translated where the dictionary has an entry |
| Saved-game keys, server routes, data field names | Intentionally Portuguese; renaming them would break existing saves and the admin panel |
| Spanish | Selectable, but has no dictionaries |
